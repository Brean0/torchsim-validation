# F003 — Fractional soft-sphere derivatives become nonfinite outside species support

**Evidence level:** measured TorchSim derivative failure, with an independent native JAX MD 0.2.29 calculation of the same potential and species parameters. CPU float64 throughout.

Use three atoms at x=[0, 1.5, 5], species=[0, 0, 1], sigma matrix `[[1,2],[2,2]]`, epsilon=1 and alpha matrix filled with **2.5**. The first pair has r=1.5 and species cutoff sigma=1, but the global neighbor cutoff 2 retains it. All pairs are outside their species interaction support. The potential is identically zero in a neighborhood of these coordinates, so its force must be finite and zero there.

## Measured results

| Measurement | TorchSim (`alpha=2.5`) | Native JAX MD (`alpha=2.5`) | TorchSim integer control (`alpha=2`) |
|---|---|---|---|
| Total energy | 0 | 0 | — |
| Atom 0 force | `[nonfinite, nonfinite, nonfinite]` | `[0,0,0]` | `[0,0,0]` |
| Atom 1 force | `[nonfinite, nonfinite, nonfinite]` | `[0,0,0]` | `[0,0,0]` |
| Atom 2 force | `[0,0,0]` | `[0,0,0]` | `[0,0,0]` |
| Nonfinite force components | **6** | **0** | **0** |

The integer-exponent case is a control with a different alpha. Its force values were retained; its energy was not, so that cell is marked —. Nonfinite components are stored as JSON `null` in the evidence.

TorchSim returns energy **0** but **6 nonfinite force components** on the first two atoms. The distant atom's force is [0,0,0]. The same TorchSim case with integer alpha=2 returns all-zero forces. Native JAX MD `energy.soft_sphere_pair` plus `quantity.force` returns energy **0** and all **9 force components zero** with alpha=2.5 and the same sigma matrix and species. That result comes from an isolated interpreter that never imports TorchSim.

The suspected mechanism is visible in [TorchSim `soft_sphere_pair`, lines 35–59](https://github.com/TorchSim/torch-sim/blob/d6d8e9fc30129e01a05b551c2d71912821c9b68b/torch_sim/models/soft_sphere.py#L35-L59): a negative base is raised to a fractional power before the result is masked. Energy masking can hide that invalid intermediate while differentiation still propagates a nonfinite derivative. JAX MD's installed `jax_md/energy.py`, `soft_sphere` at lines 123–171, uses `util.safe_mask` for fractional alpha. The exact [0.2.29 wheel](https://files.pythonhosted.org/packages/d6/2f/e4763555e3b8c66805090147956f57f0d134a67fb8aaccadcebec7362425/jax_md-0.2.29-py3-none-any.whl) is pinned through its [release](https://pypi.org/project/jax-md/0.2.29/), and the evidence records installed source SHA256 values. [Native soft-sphere API documentation](https://jax-md.readthedocs.io/en/main/jax_md.energy.html#jax_md.energy.soft_sphere_pair) describes the reference API; the wheel and checksums define the tested implementation.

## Recommended change (proposed)

Guard the power's input before evaluating it in both `soft_sphere_pair` and `MultiSoftSpherePairFn.forward`, at `torch_sim/models/soft_sphere.py`, audited lines 58–59 and 166–167. Outside `dr < sigma`, substitute a positive base and then mask the resulting energy to zero:

```python
mask = dr < sigma
base = torch.where(mask, 1.0 - dr / sigma, torch.ones_like(dr))
energy = epsilon / alpha * base.pow(alpha)
return torch.where(mask, energy, torch.zeros_like(energy))
```

The positive inactive base avoids invalid fractional powers and their derivatives. The regression should retain `alpha=2.5`, unequal species cutoffs and a larger global neighbor cutoff, and require finite zero forces outside support. It should also check the ordinary in-support energy and derivative. This proposal has not been applied to the audited source or the saved measurements.
